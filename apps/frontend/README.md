# InsightIQ — Frontend

React + TypeScript + Vite SPA for the InsightIQ analytics platform.

## Quick Start

```bash
npm install
npm run dev
```

Runs at **http://localhost:5173**

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- ShadCN UI
- Recharts

## Build

```bash
npm run build    # produces dist/
```

## Deployment

Deployed to **Vercel** with root directory set to `apps/frontend`. See [DEPLOYMENT.md](../../DEPLOYMENT.md) for details.
